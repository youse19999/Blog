リソース¶

リソースは、Gltfから直接Vramへ転送されます。

基本的に、GLTFのバッファを、一時的にメモリにコピーした後にそのままVRAMに送られます。

このエンジンはバッファのレンダリング時の結合を禁止しています。

そのため必要なリソースは、オブジェクト側が知らせます。

リソースは、VポインタまでのCPUでの捜索のO(1)を実現するために命名のみで識別されています。 その代わりに、重複回避用のユニークIDがリソースの読み込み時に割り当てられます。 ユニークIDも命名ですが、Vポインタの中にあります。 例えば重複したリソースが発見されても、Vポインタ内の命名が優先されます。

このエンジンは親がこのリソースを読み込むのも、アクセスするのも完全に禁止されていて、GPU側が親の子のIDに行列を与える以外しません。 そのため、スケルタルアニメーションが使えないと勘違いするかもしれませんが、親が全部の行列や色情報を横並びのメモリで持ってるためそれはありません。
